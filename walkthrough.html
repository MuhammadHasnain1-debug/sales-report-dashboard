⚠ A bug worth knowing

flex-basis follows the flex direction

The search box was fine on desktop but ballooned to 220px tall on mobile. The cause: flex: 1 1 220px sets the size along the container's main axis. On desktop the row layout made 220px a width; switching to flex-direction: column on mobile turned it into a height. Fix: reset it to flex: 0 0 auto; width: 100% inside the mobile breakpoint.

ⓘ Gotcha to remember

The dashboard needs a local server

Double-clicking index.html shows empty cards. Browsers block fetch() on file:// for security, so the data never loads. The fix — and what the README says — is to serve it: python -m http.server 8000, then open localhost:8000.
